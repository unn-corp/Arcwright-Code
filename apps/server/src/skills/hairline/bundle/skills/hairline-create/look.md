# Visual criteria (unverified without an isolated preview)

The Arcwright bundle has no supported generated-code preview runner. `look.mjs` fails closed.
Do not launch a browser, install Playwright, open SVGs, or use an ordinary artifact preview.

Review source for one clear metaphor, a strong rest pose, a single stroke, no labels in the
drawing, pointer hit testing against the rest/target pose, and a short meaningful tour.
Frame containment, flicker, actual pointer response, console cleanliness and readout behavior
require visual execution and remain unverified. Say so in the handover.
